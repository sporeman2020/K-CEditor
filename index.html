KC save patcher

Applies a cell_edits.json from the editor to a save's world file, then lets you download the new world file. Everything runs in this page. Nothing is uploaded.

1. Pick the save's world file

2. Pick the edits file

3. Build the patched world

Download world

Waiting for files.

Using the result

  1. Make a new folder in ...\Kingdoms and Castles\Saves\ with any new name (a GUID works).
  2. Copy summary, cover and custombanner.png from the original save folder into it.
  3. Save the downloaded file into that folder as world (no extension).
  4. Start the game and load the new save.

The patch keeps every value the same size, so the file length never changes. The original save is not modified.
