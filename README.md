# KC Save Patcher

Browser-only tool for Kingdoms and Castles save files.

1. Open the site and pick a save's `world` file.
2. Pick a `cell_edits.json` file from the editor.
3. Build and download the patched `world`.

Nothing is uploaded. The page runs entirely in your browser.

To use the result, make a new save folder, copy `summary`, `cover` and `custombanner.png` from the original save into it, and save the download there as `world` with no extension.
